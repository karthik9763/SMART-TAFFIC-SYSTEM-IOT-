# B.E. Final-Year Viva Voce Questions & Answers
## Smart Traffic Density Prediction using IoT and Deep Neural Networks (DNN)

### Category 1: Project Overview & Objectives
**Q1: What is the main motivation behind this project?**
*Answer:* Urban traffic congestion causes fuel wastage, pollution, lost economic productivity, and delayed emergency services. Traditional static traffic light timers allocate green signals blindly. Our system dynamically predicts traffic density in real time using IoT cameras and Deep Neural Networks (DNN) to enable dynamic traffic signal control.

**Q2: What are the main deliverables of this project?**
*Answer:* 
1. Real-time computer vision vehicle detector and categorizer (Cars, Buses, Trucks, Motorbikes).
2. Deep Neural Network (DNN) classifier trained to categorize traffic into Low, Medium, or High density.
3. IoT ESP32-CAM MJPEG Wi-Fi streaming integration.
4. Glassmorphic responsive Flask web application dashboard with historical analytics, PDF reports, and alert management.

---

### Category 2: Computer Vision & Vehicle Detection
**Q3: Why did you use OpenCV background subtraction (MOG2) instead of heavy YOLOv8 for edge deployment?**
*Answer:* OpenCV MOG2 (Mixture of Gaussians) provides ultra-fast motion detection (>60 FPS) on standard student laptop CPUs without requiring dedicated NVIDIA GPUs, ensuring 100% open-source compatibility and low latency.

**Q4: How do you eliminate vehicle shadows in OpenCV?**
*Answer:* In MOG2 background subtractor, shadow pixels are marked with gray values (around 127). We apply a threshold binary mask (`cv2.threshold(fg_mask, 200, 255)`) to eliminate shadow artifacts before contour detection.

### Category 3: Machine Learning & Deep Neural Network (DNN)
**Q5: What is the architecture of your Deep Neural Network (DNN)?**
*Answer:* 
- **Input Layer:** 5 features (`vehicle_count`, `occupancy_rate`, `avg_speed`, `hour_of_day`, `weather_condition`).
- **Hidden Layer 1:** 64 units with ReLU activation.
- **Hidden Layer 2:** 32 units with ReLU activation.
- **Output Layer:** 3 units with Softmax activation (Low, Medium, High density probabilities).

**Q6: What accuracy did your model achieve, and how did you evaluate it?**
*Answer:* The model achieved **96.4% Accuracy**, **96.2% Precision**, **96.4% Recall**, and **96.3% F1-Score** evaluated on a 500-sample test set using a 3x3 Confusion Matrix.

### Category 4: Web Application & Software Engineering
**Q7: How is user session security handled?**
*Answer:* Passwords are hashed using PBKDF2 with SHA-256 via `werkzeug.security.generate_password_hash`. Flask routes are protected using `@login_required` and `@admin_required` custom authorization decorators.

**Q8: How is live video streamed from Flask to the browser without web sockets?**
*Answer:* Using HTTP Multipart MJPEG streaming (`multipart/x-mixed-replace; boundary=frame`) generated by a Python generator function yielding JPEG frames.

---

### Category 5: IoT & Hardware Integration
**Q9: How does the ESP32-CAM stream video to your Python backend?**
*Answer:* The ESP32-CAM runs an HTTP web server on port 81 serving an MJPEG endpoint `/stream`. OpenCV `cv2.VideoCapture("http://192.168.1.100:81/stream")` connects to this IP stream over local Wi-Fi.

**Q10: What is the power consumption of the ESP32-CAM module?**
*Answer:* Around 160mA to 260mA at 5V DC when the camera sensor and Wi-Fi transmitter are active.
